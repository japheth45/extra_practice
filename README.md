# Module 10 project

This folder is empty on purpose. It is where your Module 10 project starts.

The Project Menu and the Project Guide are in the Hands-on > Module 10 folder on
your desktop. The guide prints the commands to set up this folder, install a
package when your project needs one, and work through the planning, build, and
review conversations with Codex. If your project uses one of the seed-data
files, drag that file in from the seed-data folder.

Everything you build goes in this folder, under Git, one commit per phase.
